# Tasks: Playground redesign (per-task office + Flow view)

**Input**: `specs/008-playground-redesign/` — [spec.md](spec.md), [plan.md](plan.md),
[research.md](research.md), [data-model.md](data-model.md),
[contracts/api.md](contracts/api.md), [quickstart.md](quickstart.md)

**Tests**: test-first (orchestrated implementation): each package writes the failing tests
listed in its tasks before the code.

**Checks**: Rust `cargo test -p delilah-agents` / `-p delilah-daemon`; app
`cd app && npx tsc --noEmit && npx vitest related --run <files>` (run vitest with
`--no-cache` after adding files under `app/src/i18n/en/`).

**Visual design**: follow [research.md R10](research.md) (the app's design system from the
design artifacts: framed `--term` inset with a 30px header, `.seg` toggle, status tokens
for state, accent only for "needs you", no gradients/shadows, works at ~600px).

**Conventions** (UI v2): one component per file with its own `.css` and
`app/src/i18n/en/<Component>.ts`; theme tokens from `styles.css`; type ≥ 12px; Spanish UI
strings through `t()`; `prefers-reduced-motion` honoured; no JS animation loop.
